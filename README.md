# Школьный Telegram-бот — версия 2

Бот предназначен для информационной поддержки образовательного учреждения.

Официальный сайт:
https://shkola-kaltuk.gosuslugi.ru

## Запуск

1. Установите Python 3.11 или новее.
2. Откройте PowerShell/терминал в папке проекта.
3. Установите зависимости:

    py -m pip install -r requirements.txt

4. Откройте `.env`.
5. Вставьте НОВЫЙ токен бота от @BotFather:

    BOT_TOKEN=...

6. Запустите:

    py bot.py

## Команды

/start — главное меню
/help — помощь
/status — состояние базы знаний

## Что изменилось во второй версии

- Бот не теряет старую базу, если сайт временно не отвечает.
- Кэш базы хранится в `data/knowledge.json`.
- Состояние последнего обновления хранится в `data/status.json`.
- Сайт проверяется несколькими короткими попытками.
- Добавлена команда `/status`.
- Добавлена более аккуратная обработка HTML.
- База автоматически обновляется каждые 6 часов.

## Важное ограничение

Портал может блокировать/замедлять автоматические запросы. Если в логе будет
`Read timed out`, это означает, что сервер сайта не успел ответить.
В этом случае бот продолжает работать с последней сохранённой базой.

Следующим этапом можно добавить специализированный импорт данных портала,
ИИ-поиск по базе и админ-панель.

## Безопасность

Не публикуйте токен Telegram-бота. Если токен был показан кому-либо,
перевыпустите его через @BotFather и замените значение в `.env`.
